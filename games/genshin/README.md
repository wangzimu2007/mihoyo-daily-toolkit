# 原神（BetterGI）

用 [BetterGI](https://github.com/babalae/better-genshin-impact) 的「一条龙」跑每日，
外层用 PowerShell 包装：切分辨率 → 启动 → 保焦点 → 跑 → 判据 → 关游戏 → 还原。

## 每日内容

一条龙配置（`User/OneDragon/每日委托.json`）里的任务顺序：

```
合成树脂 → 自动秘境 → 领取邮件 → AutoCommissionNova（委托） → 领取每日奖励 → 领取尘歌壶奖励
```

| 任务 | 作用 | 完成标志 |
|---|---|---|
| 合成树脂 | 60 原粹 + 1 晶核 → 浓缩树脂 | 日志出现合成记录 |
| 自动秘境 | 消耗树脂刷本 | `体力耗尽` / `轮次已达标` |
| 领取邮件 | 领邮箱奖励 | 邮件任务段结束 |
| AutoCommissionNova | 4 个每日委托 | `共执行 N/N 个委托` |
| 领取每日奖励 | 委托奖励 + 探索派遣 + 纪行 | `今日奖励已领取` |
| 领取尘歌壶奖励 | 洞天宝钱 + 好感 | 洞天任务段结束 |

> 「探索派遣」BGI 只做**检查**（未到期时报「未探索完成或已领取」属正常）；
> 派遣需要玩家自己在游戏里重新派出。

## 判据（本仓库 `run-with-restore.ps1` 的口径）

一次运行算 **OK** 需要同时满足：

1. 日志出现 `一条龙和配置组任务结束`
2. 出现 `体力耗尽` / `轮次已达标` / `完成\d星圣遗物快速分解` 之一
3. 出现 `今日奖励已领取` / `每日奖励已领取` / `检查每日奖励：已领取`
4. 运行窗口内**没有** `模拟键鼠消息发送失败` / `当前获取焦点的窗口为`

任一条不满足 → 记 `FAIL` 并写 `ALERT.txt`。

## 脚本

| 文件 | 作用 |
|---|---|
| `run-with-restore.ps1` | 单次运行包装器：输入自检 → 切 1080p → 启动 → 拉焦点 → 跑一条龙 → 判据 → 关游戏 → 还原 4K |
| `display.ps1` | 改注册表切分辨率（原神只在启动时读取，需重启游戏生效） |

## 专属坑

1. **战斗策略文件必须在 `User/AutoFight/` 根目录**
   配置写的是 `万能战斗策略（萌新推荐）`，程序不去子目录找。
   放在 `AutoFight/群友分享/` 下会导致**所有需要战斗的委托失败** → 委托永远 3/4 → 每日奖励永远领不到。
2. **游戏窗口必须在前台**，否则 BGI 的 `SendInput` 会打到别的窗口上，日志报
   `模拟键鼠消息发送失败！常见原因：1.未以管理员权限运行；2.存在安全软件拦截`。
   对策：启动后每 8 秒拉一次焦点，等待循环里每 60 秒复查一次前台进程。
3. **必须 1080p 窗口化**。4K 下 UI 缩放会让识图失败率飙升；跑完再切回 4K。
4. **OCRArtifacts 不会自己切背包页签**：直接跑会扫成武器。必须先跑一个会点页签的脚本
   （本仓库用「读取圣遗物数量」）再跑扫描。
5. **判据不能只看日志尾部**：委托阶段会写上千行，会把秘境阶段的「体力耗尽」冲掉。
   必须按运行起始时间过滤整份日志。

## 要改的路径（首次使用）

脚本已把安装目录抽成两个变量（也可用环境变量覆盖）：

| 变量 | 默认值 | 环境变量 |
|---|---|---|
| `$BgiRoot` | `D:\software\BetterGI` | `BGI_HOME` |
| `$ZzzRoot` | `D:\software\ZenlessZoneZero-OneDragon` | `ZZZ_OD_ROOT` |

另有三个跨目录依赖，需确认存在：

| 依赖 | 期望位置 |
|---|---|
| `pad-auto.ps1` | `games/zzz/` |
| `zzz-focus.ps1` | `games/zzz/` |
| `request.json` / `dispatcher.ps1` | `examples/`（两边必须指向同一目录） |
